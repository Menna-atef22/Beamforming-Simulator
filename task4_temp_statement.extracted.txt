Task 4 – Beamforming Simulator for Multi-Domain
Applications (Ultrasound, 5G, Radar)
Beamforming and direction of arrival (DOA) are fundamental concepts in modern technolo-
gies including wireless communications (e.g., 5G), radar systems, and biomedical imaging such
as ultrasound. The core principles rely on phase shifts, time delays, and constructive/destructive
interference to steer and shape beams in space.
Description:Develop a comprehensive 2D web-based simulator that demonstrates beam-
forming concepts across multiple application domains. The simulator should be modular and
support at least three independent modes:Ultrasound Imaging,5G Communication, and
Radar Detection. The user should be able to explore, visualize, and control beamforming
behavior in real time.
General Requirements (Applicable to All Modes)
•The user should be able to:
–Control the number of transmitters/receivers (probes/elements).
–Adjust phase shifts and/or time delays for each element in real time.
–Customize operating frequency/frequencies.
–Modify the geometry of the array (linear, curved), with full control over curvature param-
eters.
•Each element (probe) should emit avisualized signal(e.g., dotted wave propagation) that
reflects realistic spreading behavior.
•The resulting beam (from constructive/destructive interference) should be visualized as a
distinct, emphasized beam profile(e.g., thicker line or intensity map).
•The simulator should providesynchronized viewersshowing:
–Individual element contributions.
–Combined interference pattern.
–Final beam direction/profile.
•The user should be able to steer the beam dynamically by modifying delays/shifts.
•Support multiple phased array units operating simultaneously.
•Provide parameter setting files for predefined scenarios that can be loaded, modified, and
saved.

Mode 3: Radar Beamforming Simulator
•Simulate a radar system based on phased array beam steering.
•The system should:
–Display a circular detection area.
–Continuously scan the environment using asteered beam(not a simple rotating line).
•The beam movement should be achieved by:
–Dynamically adjusting delays/phases of array elements (beamforming-based scanning).
•The user should be able to:
–Control scan speed and direction.
–Adjust array parameters and observe their effect on detection.
•Objects/targets should be placed in the environment, and the system should:
–Detect targets when they fall within the beam.
–Visually indicate detection events.
•Compare traditional “rotating line radar visualization” with beamforming-based steering.
